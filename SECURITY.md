# Security

This policy applies to every kadet-hub repository without a SECURITY.md of
its own.

Report a vulnerability privately through GitHub's private vulnerability
reporting: the repository's Security tab, "Report a vulnerability". Without
a GitHub account, write to security@kadet-hub.org. Do not open a public
issue.

Vulnerabilities in the marketplace itself and listed generators that
behave maliciously are covered by
[kadet-hub/registry's SECURITY.md](https://github.com/kadet-hub/registry/blob/main/SECURITY.md).

Supported is the newest release, or the default branch in a repository
without releases. Reports are handled on a best-effort basis, without a
fixed response time.

A fixed vulnerability is published as a GitHub security advisory with the
affected versions and a CVSS score.
